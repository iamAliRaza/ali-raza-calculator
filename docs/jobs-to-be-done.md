# Jobs To Be Done

**Job J-1 (Student).** "When some of my course assessments have been marked and others are still to come, I want to understand how my results so far add up overall, so I can judge how well I am really doing rather than guessing from individual marks that carry different weights."

**Job J-2 (Student).** "When the remaining assessments in a course are approaching and I am aiming for a particular final grade, I want to know how well I must do on them, so I can plan my study effort, or change my goal if it is no longer reachable."

**Job J-3 (Instructor).** "When all of a student's assessments have been marked, I want to work out their final grade exactly as the course weighting defines it, so I can record a grade that is correct and that I can justify."

**Job J-4 (Instructor).** "When a student questions their grade or a mark changes after review, I want to see how the change affects their final result, so I can respond with confidence and correct the record if needed."
